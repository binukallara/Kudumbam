കുടുംബ ശാഖകൾ (മക്കൾ)

താഴെ നൽകിയിരിക്കുന്ന 8 മക്കളിൽ ആരുടെയെങ്കിലും കാർഡിൽ ക്ലിക്ക് ചെയ്താൽ അവരുടെ പങ്കാളി, മക്കൾ, പേരക്കുട്ടികൾ എന്നീ മുഴുവൻ വിവരങ്ങളും താഴെ തെളിയും.

1
തിരഞ്ഞെടുത്ത കുടുംബശാഖ

ശാഖാ വിവരങ്ങൾ

വിവരങ്ങൾക്കായി ഏതൊരു കാർഡിലും ക്ലിക്ക് ചെയ്യുക
ഈ വെബ്‌സൈറ്റിലെ ഫോട്ടോകളും പേരുകളും എങ്ങനെ മാറ്റാം? (How to Edit)

1. ഈ ഫയൽ (`index.html`) ഏതെങ്കിലും ഒരു കോഡ് എഡിറ്ററിൽ (VS Code / Notepad) തുറക്കുക.

2. ഫയലിന്റെ താഴെയുള്ള <script> ടാഗിന് ഉള്ളിലെ familyData എന്ന ഒബ്ജക്റ്റിൽ മുത്തശ്ശന്റെയും മുത്തശ്ശിയുടെയും, 8 മക്കളുടെയും അവരുടെ കുടുംബാംഗങ്ങളുടെയും പേരുകളും ഫോട്ടോ ലിങ്കുകളും നിങ്ങൾക്ക് നൽകാം.

3. ഫോട്ടോകൾ നിങ്ങളുടെ കമ്പ്യൂട്ടറിലെ images/person.jpg ഫോൾഡറിലോ അല്ലെങ്കിൽ ഓൺലൈൻ ലിങ്കുകളായോ നൽകാം.

4. ശേഷം ഈ ഫയൽ നിങ്ങളുടെ GitHub Repository-ൽ അപ്‌ലോഡ് ചെയ്ത് Settings -> Pages വഴി ഒരു മിനിറ്റിനുള്ളിൽ ഫ്രീയായി ലൈവ് ആക്കാവുന്നതാണ്!
